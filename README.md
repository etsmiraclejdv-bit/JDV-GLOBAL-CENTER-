## 4. Écran de Démarrage

### Flux d'Onboarding Complet

```
01. Splash Screen JDV GLOBAL CENTER
    ├── Logo JDV
    ├── JDV GLOBAL CENTER
    └── "Votre monde, connecté"

02. Bienvenue
    ├── Créer un compte
    ├── Se connecter
    └── Continuer en mode découverte

03. Sélection du pays
    └── Liste des pays disponibles

04. Sélection de la langue
    └── Langues supportées

05. Sélection de la devise
    └── Devises disponibles

06. Création du compte
    ├── Email/Téléphone
    ├── Mot de passe
    └── Conditions d'utilisation

07. Vérification téléphone/email
    └── Lien de confirmation

08. OTP (One-Time Password)
    ├── Code SMS
    └── Code Email

09. Création du profil
    ├── Photo de profil
    ├── Nom complet
    ├── Prénom
    ├── Date de naissance
    └── Autres informations

10. KYC (Know Your Customer)
    ├── Vérification d'identité
    ├── Documents requis
    └── Contrôle de conformité

11. Sécurité / PIN
    ├── Création du PIN
    └── Confirmation

12. Biométrie
    ├── Empreinte digitale
    ├── Reconnaissance faciale
    └── Configuration optionnelle

13. HOME JDV GLOBAL CENTER
    └── Tableau de bord principal
```

### Points Clés
- ✅ Processus d'onboarding clair et progressif
- ✅ Vérification multi-étapes pour la sécurité
- ✅ Intégration KYC dès le départ
- ✅ Options de biométrie
- ✅ Support multilingue et multi-pays

║ ACC EXPLORER SERVICES MSG PROFIL           ║
╚════════════════════════════════════════════╝
```

### Éléments de Navigation

| Icône | Label | Fonction |
|-------|-------|----------|
| 🏠 | ACCUEIL | Accès au home/hub central |
| 🔍 | EXPLORER | Découverte des branches et services |
| 📦 | SERVICES | Accès rapide aux services principaux |
| 💬 | MESSAGES | Messagerie centrale |
| 👤 | PROFIL | Gestion du profil utilisateur |

### Bouton Central Intelligent (Hub d'Actions Rapides)

```
                    ┌─────────────┐
                    │   💰 PAY    │
                    └─────────────┘
       ┌────────────────────────────────────────┐
       │                                        │
    ┌──┴──┐                               ┌─────┴─┐

       ├────────────────────────────────────────┤
       │                                        │
    ┌──┴──┐                               ┌─────┴─┐
    │ 🛒  │                               │  🔔   │
    │Cmd  │                               │Réserv │
    └─────┘                               └───────┘

### Actions Disponibles au Centre
- 💰 **JDV PAY** - Accès au portefeuille et paiements
- 📱 **SCANNER** - Scan de codes QR/codes-barres
- 🔍 **RECHERCHE** - Recherche globale
- 🤖 **IA** - Assistance JDV AI
- 🛒 **COMMANDE** - Accès rapide aux commandes
- 🏨 **RÉSERVATION** - Réservations (voyage, hôtel, etc.)
